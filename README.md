Aplicación Android desarrollada en Kotlin para gestionar el consumo de combustible, registrar repostajes y controlar los gastos de un vehículo.

Este proyecto está compuesto por:

* 📱 Aplicación móvil (Android)
* 🌐 API backend propia para la gestión de datos

---

## 🚀 Funcionalidades principales

* Registro de repostajes
* Cálculo automático de consumo medio
* Seguimiento de gastos en combustible
* Historial de operaciones
* Gestión de datos persistente mediante API

---

## 🛠️ Tecnologías utilizadas

### App (Android)

* Kotlin
* Android Studio
* Gradle

### Backend (API)

- Java
- Spring Boot
- API REST
- PostgreSQL
- Autenticación y autorización con JWT
- Arquitectura por capas (controller, service, repository)

---

## 🔐 Seguridad

La aplicación implementa autenticación mediante JWT para proteger los endpoints y gestionar sesiones de usuario.

---

## 🔗 Arquitectura del proyecto

La aplicación móvil se conecta a una API REST propia para almacenar y recuperar la información del usuario.

* La app gestiona la interfaz y lógica de usuario
* La API se encarga de la persistencia y gestión de datos

👉 Repositorio de la API:
https://github.com/ToniRumen/Api_Drivy
